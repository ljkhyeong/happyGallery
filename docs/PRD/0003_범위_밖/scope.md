# 범위 밖 항목

초기 버전에서 명시적으로 제외하거나 후순위로 미루는 항목을 정리한다.

상품·클래스 설명과 대표 이미지 관리, 공방 프로필, 관리자 이미지 업로드와 자가 호스팅 미디어 백업은 현재 구현 범위이므로 이 목록에서 제외한다.

---

## 현재 제외 범위

1. 오프라인 POS 실시간 연동
   - 초기에는 운영 정책으로 재고/주문 충돌을 흡수한다.
2. 추천/커뮤니티 기능
   - 개인화 추천과 사용자 간 커뮤니티는 MVP 핵심 기능이 아니므로 제외한다.
3. 번들 결제 (상품 + 예약 동시 결제)
   - PRD §6에 정의되어 있으나 1차 배포에서 제외한다. 스키마(`orders.bundle_id nullable`)는 준비 완료.
4. 이메일/앱 푸시 알림 채널
   - PRD §7의 3·4순위 채널. 1차 배포는 NHN Cloud Alimtalk(카카오 알림톡) + SMS fallback만 운영한다.
5. 다중 공방 입점형 마켓플레이스
   - 현재 서비스는 해피갤러리 한 곳의 클래스·작품·운영 정보를 직접 제공하는 공식 서비스다.
   - 입점형 전환에는 공방별 소유권, 판매자 권한, 입점 심사, 주문 분리, 수수료·정산·세금, 분쟁·콘텐츠 관리가 필요하므로 기존 단일 공방 모델에 부분적으로 추가하지 않는다.
   - 협업 작가 수업은 해피갤러리가 판매·환불 책임을 지는 자체 클래스로 먼저 검증하고, 별도 마켓 사업성이 확인될 때 독립 PRD로 재검토한다.

---
