# ADR-0049: 월 2~3만 원 클라우드 운영 기준

**날짜**: 2026-09-05  
**상태**: 보류 — 보유 노트북 설치·검증을 우선, 클라우드는 대체 후보

## 현재 적용 범위

클라우드 비교 후 운영자가 i5-8250U·RAM 16GB 노트북의 Windows 삭제·Linux 설치와 24시간 가동이 가능하다고 확인했다. 현재 실행 방향은 [ADR-0037](../0037_자가_호스팅_배포_토폴로지_기준/adr.md)의 노트북에 먼저 설치해 검증하는 것이다. 아래 VM 결정과 견적은 클라우드로 전환할 때 다시 검토할 조건으로 보관한다. VM 구매·DNS 변경은 실행하지 않았으며, 노트북의 실제 운영 가능 여부는 [노트북 설치 준비](../../../deploy/laptop/README.md)의 회선·부하·복원 검증 후 판단한다.

## 배경

운영자가 `happy-gallery.com` 도메인을 준비했고, 처음에는 소유 노트북 대신 월 2~3만 원 내외의 클라우드 사용을 요청했다. 당시에는 ADR-0037의 노트북·공유기 전제를 VM으로 바꾸는 안을 비교했다. 기존 서비스 배포와 데이터 보호 절차는 재사용할 수 있다.

## 클라우드 전환 시 검토할 조건

- 초기 구성은 Linux 가상서버 한 대에 기존 단일 노드 k3s를 설치하는 안을 기준으로 검토한다. 한국 이용자 기준으로 서울 리전을 우선하며 AWS Lightsail을 먼저 비교한다. 기존 일본 8GB 견적은 구매 보류다. 메모리 한도 합계를 실제 필요량으로 취급하지 않으며, 2GB·4GB 운영 가능 여부는 구성 조정과 부하 검증으로 판단한다. 배포 방식이나 모니터링 구성을 바꾸면 별도 구현·검증과 문서 갱신을 선행한다.
- `deploy/k3s`의 app, frontend, MySQL, Redis, Prometheus, Alertmanager, Grafana와 TLS ingress를 재사용한다. 관리형 DB·Redis·Kubernetes·로드밸런서를 추가하지 않는다. 개발용 Compose는 계속 개발·복구 진단용이다.
- Cloudflare DNS의 대표 주소를 `happy-gallery.com`으로 연결한다. 초기에는 DNS only를 사용해 기존 Traefik 신뢰 경계를 유지한다. Cloudflare 프록시를 켤 때는 허용 IP·forwarded header·rate limit·캐시·결제 callback을 별도 검증한다.
- 외부 공개는 TCP 80/443, SSH는 운영자 IP에 한정한다. Kubernetes API, DB, Redis, app와 관리·모니터링 포트는 공개하지 않는다. 모니터링 화면과 클러스터 관리는 SSH 터널을 사용한다.
- DB·미디어·배포 이미지와 메타데이터는 다른 업체의 원격 저장소에 기존 `age` 암호화 복구 묶음으로 보관한다. 운영 VM의 디스크·스냅샷만으로 백업을 대체하지 않는다. 복구 키는 VM과 백업 계정 양쪽에서 분리해 운영자가 보관한다.
- 기존 6시간 백업·30일 보존을 유지한다. 현재 백업은 app을 중지하므로 최대 약 6시간의 데이터 복구 간격과 정기 중단을 수반한다. 원격 저장소에서 실제 백업·재시작 시간을 측정하고, 운영 가능한 중단 시간이 아니면 공개 전에 백업 개선을 선행한다.
- 단일 VM 장애는 전체 서비스 중단이다. 외부 uptime 감시와 백업 실패 알림을 설정하고 다른 VM으로 복원하는 훈련을 완료해야 운영 개시로 판단한다.
- 월 예산은 우선 서버·백업 등 인프라 기준으로 계산한다. 문자·알림톡·이메일·결제 수수료·도메인 갱신 포함 여부는 운영자 답변으로 확정한다. 무료 체험·장기 선결제를 정상 월 비용으로 계산하지 않는다.

## 재사용하는 기준

ADR-0037의 동일 origin, 비공개 저장소, 운영 Secret 허용 목록, `prod` 불변식, AES/HMAC 키와 DB 비밀번호 회전, 복구 묶음 검증, 호환 이미지와 Flyway 롤백 경계를 유지한다. 물리적인 노트북 대신 클라우드 VM에 적용한다.

현재 우선 후보는 AWS Lightsail 서울이다. 2GB는 원래 예산 안의 운영 가능성을 먼저 검증해야 하고, 4GB는 월 3만 원을 넘으므로 예산 변경이 확정되기 전 구매하지 않는다. 백업 저장 국가·업체도 함께 다시 선택한다. Contabo 일본과 Hetzner 유럽 백업의 기존 견적은 비교 기록으로만 유지한다. 대안 비교와 개통 절차의 원본은 [`deploy/cloud/README.md`](../../../deploy/cloud/README.md)다.

## 현재 검증 범위

공개 DNS와 공급자 요금, 저장소 manifest·운영 스크립트를 확인했다. 서버 구매, DNS 변경, 실제 HTTPS 배포, 외부 백업 복원과 실결제 검증은 아직 실행하지 않았다. 현재 노트북 설치·검증 단계에서도 클라우드 견적이나 정적 검증을 실제 운영 성공으로 취급하지 않는다.
