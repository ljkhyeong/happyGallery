# UAT 문서

이 디렉터리는 운영 전 실사용자·관리자 인수 검수(User Acceptance Test)의 시나리오와 실행 기록을 관리한다.

- 제품의 기대 동작은 [`docs/PRD`](../PRD/)가 소유한다.
- 자동 테스트의 선택 기준은 [ADR-0027](../ADR/0027_테스트_전략과_최소_테스트_세트_기준선/adr.md)이 소유한다.
- UAT 문서는 실제 화면에서 고객과 관리자가 기대 동작을 완주했는지와 그 실행 증거를 소유한다.

## 실행 기록 규칙

실제 실행 기록은 가이드와 같은 디렉터리의 `runs/` 아래에 다음 이름으로 추가한다.

```text
<순번>_<YYYY-MM-DD>_<release-id 또는 short-sha>.md
```

예: `0001_2026-08-20_c5bcb2ab.md`

- 실행 기록은 결과 양식을 복사해 작성한다.
- 계정은 `member-uat-01` 같은 별칭만 기록한다.
- 비밀번호, 인증 코드, 세션·접근 토큰, 결제 키, 전체 전화번호·이메일·주소는 저장소에 남기지 않는다.
- 개인정보가 포함된 원본 화면·영상은 저장소가 아니라 접근이 통제된 별도 위치에 보관하고, 실행 기록에는 정제된 증거 링크만 남긴다.
- 기대 결과를 UAT 문서에 새 정책처럼 추가하지 않는다. 동작이 바뀌면 PRD를 먼저 갱신하고 시나리오는 해당 PRD를 참조한다.
