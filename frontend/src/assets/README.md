# 소셜 로그인 아이콘

- Google: [공식 로그인 디자인 가이드](https://developers.google.com/identity/branding-guidelines)의 [G 이미지](https://developers.google.com/static/identity/images/g-logo.png)를 원본으로 사용한다.
- 카카오: [공식 리소스](https://developers.kakao.com/tool/resource/login)의 [로그인 SVG](https://developers.kakao.com/tool/images/resource/preview/login-complete-ko.svg)에서 말풍선 심볼 경로만 추출했다. 형태·비율을 유지하고 공식 가이드의 검정색으로 표시한다.
- 네이버: 기존 `naver-login-icon.png`를 유지한다.

세 버튼은 공통 높이 48px와 아이콘 영역 40px를 사용한다. Google·카카오 심볼은 영역 안에 20px 크기로 표시하며, 네이버 원본 이미지는 포함된 여백을 유지한다.
